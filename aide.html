Démarrer

  1. Créez un compte : pseudo, courriel, mot de passe et couleur d'avatar.
  2. Vous arrivez dans la messagerie. Dans l'onglet Salons, tapez le pseudo d'une autre personne inscrite dans le champ « Écrire à… » puis cliquez sur Écrire : la conversation privée s'ouvre et la personne est ajoutée à vos contacts.
  3. Pour discuter à plusieurs, cliquez sur ＋ Nouveau salon de groupe, donnez un nom et cochez au moins un contact.

Utiliser la messagerie

  • Envoyer un message : touche Entrée ou bouton Envoyer (Maj + Entrée pour aller à la ligne).
  • Envoyer une image : bouton 📎, copier-coller (Ctrl + V) ou glisser-déposer dans la conversation (PNG, JPEG, GIF, WEBP, 5 Mo maximum).
  • Réagir : survolez un message (ou touchez-le sur téléphone) puis cliquez sur ☺ et choisissez un emoji. Cliquez à nouveau sur une réaction pour la retirer.
  • Membres d'un salon : bouton 👥 en haut de la conversation pour voir les membres, en ajouter ou quitter le salon.
  • Notifications : bouton 🔔 / 🔕 pour activer ou couper le son. Autorisez les notifications du navigateur pour être prévenu quand l'onglet est en arrière-plan.
  • Profil : page Mon profil pour changer de pseudo, de couleur ou de mot de passe.

Mode démo et Supabase

Babil fonctionne de deux façons, choisies automatiquement selon le fichier js/config.js :

Mode démo (par défaut)

Si js/config.js n'est pas rempli, les comptes et messages sont enregistrés dans votre navigateur. Tout fonctionne (inscription, salons, temps réel, images…), mais uniquement entre les onglets de ce navigateur. Pour tester une conversation, ouvrez un deuxième onglet, inscrivez-y un autre compte, et discutez d'un onglet à l'autre.

Mode Supabase (messagerie entre plusieurs appareils)

  1. Créez un projet gratuit sur supabase.com.
  2. Dans SQL Editor, exécutez tout le fichier supabase/schema.sql.
  3. Dans Authentication → Sign In / Providers → Email, désactivez Confirm email (pour les tests).
  4. Dans Authentication → URL Configuration, ajoutez l'adresse du site (GitHub Pages).
  5. Dans Project Settings → API, copiez l'URL du projet et la clé anon public dans js/config.js.

La note « Mode démo » de la messagerie disparaît alors, et tous les utilisateurs du site partagent la même base de données.

Questions fréquentes

Mon ami ne voit pas mon compte quand il ajoute mon pseudo.

En mode démo, les comptes n'existent que dans votre navigateur. Configurez Supabase pour que tout le monde partage les mêmes comptes.

« Impossible de joindre le serveur » lors de la connexion.

L'URL ou la clé de js/config.js est incorrecte, ou le projet Supabase est en pause. Vérifiez-les dans Project Settings → API.

L'inscription indique « Confirmez votre adresse ».

La confirmation par courriel est activée dans Supabase. Cliquez sur le lien reçu, ou désactivez Confirm email dans Authentication.

Je n'entends pas le son des notifications.

Le navigateur n'autorise le son qu'après un premier clic dans la page. Vérifiez aussi que le bouton affiche 🔔 et non 🔕.

Le site ne s'affiche pas quand j'ouvre le fichier index.html directement.

Les modules JavaScript exigent un serveur : utilisez l'extension Live Server de VS Code, python -m http.server, ou GitHub Pages.
